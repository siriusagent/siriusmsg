# Security

SiriusMsg handles local Messages data. Please report suspected vulnerabilities
privately through GitHub private vulnerability reporting if it is available on
this repository, or by contacting the repository owner through GitHub.

Do not open a public issue containing message bodies, local database excerpts,
tokens, signing details, crash logs with private paths, or screenshots that show
private conversations.

Useful reports include:

- affected SiriusMsg version
- macOS version
- whether the app was installed from the notarized DMG
- a concise reproduction path
- redacted diagnostics that do not include message bodies
