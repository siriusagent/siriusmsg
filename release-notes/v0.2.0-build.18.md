# SiriusMsg 0.2.0 (build 18)

- Fixed Codex connections installed through npm starting from Finder when Node is absent from the app's PATH. SiriusMsg resolves the installed native Codex engine for both its managed server and proxy.
- Updated discovery for the current Codex desktop app layout and owner-validated socket links. Readiness still requires a successful connection handshake; startup failures show more useful guidance.
- Show contact names in direct-chat and phone/email rows after Contacts permission is granted. Names refresh when Contacts changes or the app becomes active, and can be searched locally. Ambiguous matches keep the number or address; group titles are preserved.
- Preserve the selected person's name when adding a chat through the system Contacts picker. The picker remains available when general Contacts access is declined.
- Contact names stay in the app on this Mac and are not sent to agents. Added the app's required Contacts privacy description and signed entitlement, plus guidance when access is denied.
- Keep long-lived connection readers and stalled control requests from occupying shared worker pools, preserving control deadlines and cancellation cleanup.

Known limitations: recipient-visible typing dots remain unreliable and the Typing indicators control remains disabled. Full sleep/wake and installed login-item recovery certification remains separate. This update's contact matching is covered by automated tests; live address-book name display depends on the user's Contacts grant. This release does not claim new live message-send or model-turn qualification.
